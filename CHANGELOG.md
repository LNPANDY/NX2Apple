# Changelog

The release history of NX2Apple, newest first. Every release, with its full text, is on the [releases page](https://github.com/LNPANDY/NX2Apple/releases). 中文：[CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md).

Newest first. The fork follows upstream daily, so its game list and host fixes arrive automatically.

| Date | Version | What changed |
|---|---|---|
| 2026-11-01 | v1.0.1 | **The shell finds each game by its image** (#441, #443): the shared game-data folder on the iPhone or iPad no longer needs one folder per game. Each game is matched by the identity of its `romfs.img`, up to two levels below the chosen folder, whatever the folders are called. **Upstream moves to `cd859c38`** (#444): the engine alone can now do these things, by upstream's own notes and not checked in the launcher: Donkey Kong Bananza (Switch 2, tested through the first level, Mac only) and Hollow Knight play, Dead Cells has a profile, and a game builds from a folder of its files without `prod.keys`. The launcher does not build Switch 2 games or games from a folder of files yet, see #445. Shift plus an arrow key moves the right stick on the Mac. **NVN games need Xcode 27.2** (#447, #444): the new engine locks the Metal compiler of Xcode 27.2, and the launcher says so. On Xcode 27.1, update Xcode before building a game. Fixes: the several-games failure message of the new engine is still recognized (#444) |
| 2026-10-31 | v1.0.0 | **The engine comes from the release** (#267): the release app keeps its engine in its own store and builds from it. It no longer clones or pulls the repository. Settings shows the engine with a Check button, the Stable and Experimental channels and an automatic update switch. A channel switch asks first. The engine arrives with a signed `latest.json`, and the app installs nothing that fails the check. **One shell app for iPhone and iPad** (#226): the app holds all your games, with an art-led library, Cover Flow when the screen is on its side, settings for each game and controller or keyboard navigation. The iPhone / iPad target builds a game into the shell. Re-signs and reinstalls keep the game data and saves. **Launcher roundup** (#281): the library switches between Owned and Built, a slider that differs from its tested default gets a reset arrow, a new release shows as an icon at the end of the top bar, the Dock mirrors a running build, and console mode lists the games ready on this Mac first. Settings gets an uninstaller that removes the launcher's settings and engine trees. Games, saves and keys stay, and the app goes to the Trash. **The Mac icon uses Liquid Glass** (#290). **The Qt front end takes the Mac launcher's palette and Manrope font** (#222). **Upstream moves to `c5fe6b5d`** (#319): Metal 4 pipeline specialization, shared host shaders compiled during the build, parallel rewriter scans, and fixes for NVN buffer offsets, attachment capacity and depth/stencil pairing. Upstream's own fullscreen fix replaces ours. **Release candidates** (#332): a release is tested as a candidate first, so players get the exact build that was tested. Fixes: the iPhone cloud-save folder picker opens once per tap and Open stores the folder (#321), Tears of the Kingdom 1.4.2 no longer runs at double speed (#311, #312), Mario Tennis Aces gets past the rewrite step (#307) and past the crash after the shared fonts load (#314), iOS DLC in `Documents/aoc` is found (#319), the Windows toolchain checks name their fix for the link probe, SDK stubs, Metal and Git installs and pinned wheels (#206), console mode hides an idle pointer and asks again for full screen after a game (#339), a failed engine sync puts `engine/` back as it was (#338), a patch that does not apply is no longer taken for one that upstream already has (#323) |
| 2026-10-31 | v0.7.5 | **Xcode 27.2 no longer stops game builds**: Xcode's auto-update raised the Metal compiler to 32023.922 and NVN games stopped before the shader steps. A newer compiler of the recorded generation now builds on with a note in the log. Older or cross-generation compilers still warn. **On 0.7.3 or older? Update now.** Older apps cannot build games any more and show "Repository: not found". Install this version and building works again. Games and saves are kept (details in discussion #306) |
| 2026-10-31 | v0.7.4 | **The engine is fetched on its own** (#273): the update no longer bundles the engine source. Upstream fixes sync online inside the launcher, so they do not wait for a release. This needs GitHub access, and the launcher shows the progress and the reason for a failure. **Game language is a menu** like the iOS shell, set to System by default (#283). **A faster launcher**: tab switches (#297), Options and Manage sheets (#294), font and button rendering. Fixes: console mode starts a game from a window that just left full screen, a game folder inside iCloud Drive stops the build with an explanation because iCloud moves build caches away (#279), console mode hides the pointer after a few idle seconds (#280), *Restart now* opens the new copy from a helper once the old process has exited (#277). On 0.7.3 or older, `Repository: not found` means the old app's repository check no longer matches the new layout. Update to 0.7.4 and set it up again |
| 2026-10-30 | v0.7.3 | **German interface** (#225), with thanks to @kidziiii. **Saves**: find the game's save on the device itself, then pick the iPhone or iPad to sync with (#260). **zbic is bundled** (#258): it reads Nintendo's zstd-variant modules, and the dependency probe checks it. Fixes: a game whose base NSP sits in a subfolder (`nsp本体`) finds the update and DLC beside it (#240, #246), the Choose file dialog accepts NSZ and XCZ (#243), installing on a device no longer passes `--remove-existing-content`, which deleted the game data there (#266), a Chinese Windows no longer falls back to English in the Qt app (#256), cheats are marked unavailable on iPhone and iPad (#257), the bundled Python packages are hash-pinned (#259) |
