| 2026-11-02 | v1.0.2 | **Export as IPA, and the game data to a device or a drive** (#531, #416): the Install card of the Mac launcher has a switch with Install on device and Export as IPA. Export needs no device and no signing team. It builds the shared app with the frameworks of the games in the shell's library and writes an unsigned `NX2Apple.ipa` into the shell folder, for AltStore, SideStore or another tool you sign with. With the shared app, the game data is not in the IPA. Step 3 sends it to the app on a paired device or copies it to a drive or a folder, with progress and Stop. **What the IPA holds** (#542, #540): Export as IPA has a second choice. Shared app stays the default. One game, all inside makes one IPA per game with the game data in it, for tools that cannot copy data into an app. It has its own bundle ID, `org.nxnative.<title ID>`, so its saves are separate. It is built through the engine's one-game path. **Not tested end to end:** nobody has run an export on a real device or with a sideloaded app yet, and the one-game IPA was not checked with a sideloading tool either. A very large IPA can fail to install, and we do not know the size limit. See Known issues. **The Italian interface** (#528) by @Dino0005. The 38 texts of the export card, the texts of the new choice and the two new texts `shell.frameworkIncomplete` and `shell.gameLeftOut` are a machine translation for review. **A language is now one JSON file** (#478, #479, #480, #481): the Mac and the Windows launcher read the same files, the language list comes from them, and a test per front end checks every file. **The iPhone shell speaks the player's language** (#482, #485): its texts are lines of these files, and a game's settings rows show in the player's language. **A tap on a Recently played game starts it** (#457, #425), and the rows get more space. **The launcher's code moved into stores** (#456, #458, #460, #462, #466, #467, #469, #471, #473, #476, #530): no visible change. **Engine pin moves to `65501fbb`** (#536): New on the Mac by upstream's own notes, TRIANGLE STRATEGY, Castlevania: Belmont's Curse, SUPER ROBOT WARS Y, Splatoon Raiders, Super Mario RPG and Fire Emblem Fortune's Weave. The Mac settings window leaves the screen on Play. The NSP script decodes AV1 movies with dav1d and reads gzip-wrapped shader archives. Digimon's saves appear. We did not play any of it. We dropped the patches 0045 and 0052 because upstream took both changes. Upstream declined seedds/nxnative#492 (the runtime profile) and closed #755 and #839 for its own pointer hiding, so 0001, 0053, 0046 to 0050, 0032 and 0054 stay in the patch queue as fork-only. **Developer tooling:** `tools/bump_candidates.py` lists the upstream commits of a pin bump that the front ends depend on (#465). Fixes: a cut-off delete of a stale game framework no longer breaks the next build (#539). Quitting while the launcher removed one, about a minute on an external drive, left half a framework in the shared app folder, and the next build of another game failed at Prepare the shared app with "no readable game.manifest.json". Now the delete is a rename plus a background delete, mirror copies land only when complete, and an incomplete framework of another game is left out with a note that names the game and the missing file. Devices on Xcode 27.2 are found again, its `devicectl` changed the layout of the device list (#496, #488). The exFAT `._` files of a volume no longer break the Mac app pack, patch 0057 by @lucaszhongsj (#521, #486). Legacy PFS0 packages without the final name terminator are read, patch 0058, and the rewriter recognizes pointer tail calls before zero padding, patch 0059, both by @BadAppleD (#520, #519). Save to in the Build tab can create folders, by @SifatTaj (#522). **Known issues:** Export as IPA and Send game data are not tested on a real device or with a sideloaded app. One game, all inside is not verified with a sideloading tool, and a very large IPA can fail to install (the size limit is unknown). The first Play after the update rebuilds games, because the shader chain moved. The shader split can sit at 99% for several minutes at its end (#489). Breath of the Wild fills the disk (#413) and a Super Mario Odyssey shader step fails on an M1 with Xcode 27.2 (#361), both still open |
