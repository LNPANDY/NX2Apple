## English

- Fixed games opening to a black screen (e.g. Super Mario Bros. Wonder): the Mac pipeline archive is stamped for this Mac's OS version instead of the SDK's, so pipelines load instead of recompiling at first start (upstream #673)
- 26 upstream commits: emulated sampler border colours, NVN logic operations, automatic same-pass feedback snapshots
