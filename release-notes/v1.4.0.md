**v1.4.0: The launcher overhaul with a console mode / 启动器大改版与主机模式**

## English

**Highlights**

**Launcher overhaul (#1097, #1129)**
- Light and System appearance on the Mac, settings in four sections and game options in four groups
- A build queue, game data transfers, save import and export, players and a cloud save conflict choice
- Console mode for the couch: home rows, game pages, search, builds and a Home menu that pauses a game in the background
- Supported games list, stick deadzones and new languages: Spanish, Korean and Brazilian Portuguese

Code by @thehobbit85, @Haseenesss, @zatteogit, @Koshindai, @loki-inu, @rborkow, @LNPANDY, @ZhaowTao, @MartinMajewski, @mbanusic and @TeeJayBaker. The console concept is by @Koshindai (#816) and the controller interaction and Home menu by @Haseenesss (#901, #952). Ideas by @IUMonster (#658) and @zatteogit (#453).

**New**
- **Settings that differ from the tested value are marked**: a dot shows next to them, and "Use tested values" puts them back (#453, @zatteogit)
- **Supported games**: reachable from the library header and from console mode, with each game's cover (#1129, #1140)
- **Game names from the package**: the launcher reads a game's name and control data from its package itself, so the library shows no raw title ID or file size (#1125, #895)
- **iPhone and iPad shell**: saves, players, a Hold or Toggle mode for each touch key (idea by @IUMonster, #658), the Switch 2 badge, a cloud save gate and a Steam Link fallback. The controller's Options button opens the shell settings, and the in-game menu speaks the player's language (#1129)
- **Accessibility in the launcher**: labels, native switches and Reduce Motion (#627, #628, #629, @zatteogit)
- **Settings gear fades out**: on iPhone and iPad it hides after 3 idle seconds with a controller (#1029)
- **Builds that end in console mode are recorded** (#950, @Haseenesss)

**Changed**
- **Engine**: the pin moves to `81906931` (Switch 2 controllers, mesh object function, M1 iOS build, #1063) and then to `ab41d6a1`. The engine no longer needs .NET (#1125)
- **Experimental engine is never older than Stable**: when it is not ahead, the engine update row says so and offers Back to Stable (#1127, #1095)
- **Experimental builder**: stays behind its feature toggle, off for now (#993)

**Fixed**
- **Pro Controller counted twice**: one Pro Controller is one pad again and keeps its gyro (#972, #971, @Haseenesss)
- **Shader split hung at 99%**: zstd is decompressed in-process (#1037, #837, @Haseenesss)
- **PATAPON and Hogwarts Legacy aborted at boot**: `nsd:a` and `nsd:u` are served (#1038, @Haseenesss)
- **Pokopia for iOS**: it packs without a prewarm seed list (#926, @thehobbit85)
- **Joy-Con**: driver, vibration, IMU axes and gyro fixes (#1072, #1074, #1075, #1083)
- **Quitting a game on iPhone or iPad**: returns to the library with a full teardown (#986)
- **Re-signing**: a fresh 7-day profile and a live expiry, the iPhone activity title, the library state kept, and the Xcode project regenerated after a game was deleted (#1028, #1032, #978)
- **Update sheet**: says why its button is off while a build runs (#1061)
- **Dock**: opens a window after the last one was closed (#1065)
- **Copy bar**: the game data copy bar stays indeterminate until bytes are done (#1066)
- **Focus ring**: the Play and game settings buttons have a round one (#1067)
- **Hero banner**: a 1px bright seam at its bottom edge is gone (#1001)
- **Damaged NUP or RomFS**: a build stops with a named reason and the NUP table of contents is verified (#1130)
- **Test windows**: they no longer play a fade that can hold a thread for good (#1121, @Fbenhaddou)
- **Windows, Qt front end**: Unreal games with Zlib or LZ4 inline shaders, Oodle and LZ5 decoders, LÖVE and GameMaker shaders offline, run-time GLSLC shaders offline, a long link command line, slim IPA RomFS identity (@taowen), the LLVM download, the Python installer, one-click Defender exclusions, and `%ld%%` and artwork fallbacks in es, ko and pt-BR (#932, #935, #956, #970, #974, #979, #995, #1039, #1045, #1046, #1064, #1084, #1134)

**Known issues**
- **Not tested with the real thing**: a real Steam Link and Bluetooth pads (#797, #987), LiveContainer (#1049), large game data transfers to a device (#899, #1036) and the Home menu pause with a running game (#952)
- **Game names from packages**: not checked on packages of games packed before the launcher read names itself (#1125)
- **Console mode UI test**: `testActionsAndNavigation` has not been checked
- **Version 1.3.1**: it only reached release candidates, so its change (the experimental builder behind a toggle) ships here (#993)

**Requires**
- iOS or iPadOS 26 or later
- To build NVN games on a Mac: Xcode 27.2 and macOS 26.6 or later

## 中文

**重点**

**启动器大改版（#1097、#1129）**
- Mac 上有浅色和跟随系统两种外观，设置分为四个部分，游戏选项分为四组
- 构建队列、游戏数据传输、存档导入导出、玩家和云存档冲突的选择
- 适合沙发使用的主机模式：主页行、游戏页面、搜索、构建，以及能让游戏在后台暂停的 Home 菜单
- 支持的游戏列表、摇杆死区和新语言：西班牙语、韩语和巴西葡萄牙语

代码来自 @thehobbit85、@Haseenesss、@zatteogit、@Koshindai、@loki-inu、@rborkow、@LNPANDY、@ZhaowTao、@MartinMajewski、@mbanusic 和 @TeeJayBaker。主机模式的概念来自 @Koshindai（#816），手柄操作和 Home 菜单来自 @Haseenesss（#901、#952）。想法来自 @IUMonster（#658）和 @zatteogit（#453）。

**新增**
- **与已测试值不同的设置会被标出**：旁边会显示一个圆点，“Use tested values” 可将其恢复（#453，@zatteogit）
- **支持的游戏**：可从游戏库标题栏和主机模式进入，并显示每个游戏的封面（#1129、#1140）
- **从安装包读取游戏名称**：启动器自己从安装包读取游戏名称和控制数据，所以游戏库里不再显示原始 title ID 或文件大小（#1125、#895）
- **iPhone 和 iPad 外壳**：存档、玩家、每个触控按键的按住或切换模式（想法来自 @IUMonster，#658）、Switch 2 标记、云存档检查和 Steam Link 回退。手柄的 Options 键可以打开外壳设置，游戏内菜单使用玩家的语言（#1129）
- **启动器的无障碍支持**：标签、原生开关和「减少动态效果」（#627、#628、#629，@zatteogit）
- **设置齿轮会淡出**：使用手柄时，iPhone 和 iPad 上的齿轮在空闲 3 秒后隐藏（#1029）
- **以主机模式结束的构建会被记录**（#950，@Haseenesss）

**变更**
- **引擎**：固定点先升到 `81906931`（Switch 2 手柄、mesh object function、M1 iOS 构建，#1063），再升到 `ab41d6a1`。引擎不再需要 .NET（#1125）
- **实验版引擎永远不会比稳定版旧**：它没有领先时，引擎更新一行会这样说明，并提供「回到稳定版」（#1127、#1095）
- **实验性构建器**：仍放在功能开关后面，暂时关闭（#993）

**修复**
- **Pro Controller 被算作两个**：一个 Pro Controller 重新算作一个手柄，并保留陀螺仪（#972、#971，@Haseenesss）
- **着色器拆分卡在 99%**：zstd 在进程内解压（#1037、#837，@Haseenesss）
- **PATAPON 和 Hogwarts Legacy 在启动时中止**：现在提供 `nsd:a` 和 `nsd:u`（#1038，@Haseenesss）
- **iOS 版 Pokopia**：没有预热种子列表也能打包（#926，@thehobbit85）
- **Joy-Con**：驱动、震动、IMU 轴和陀螺仪修复（#1072、#1074、#1075、#1083）
- **在 iPhone 或 iPad 上退出游戏**：完整释放资源并回到游戏库（#986）
- **重新签名**：强制使用新的 7 天描述文件并实时刷新到期时间，显示 iPhone 活动标题，保留游戏库状态，删除游戏后重新生成 Xcode 工程（#1028、#1032、#978）
- **更新面板**：说明构建运行时按钮为什么不可用（#1061）
- **Dock**：关闭最后一个窗口后可以再次打开窗口（#1065）
- **复制进度条**：游戏数据复制进度条在字节数出来之前保持不确定状态（#1066）
- **焦点环**：「开始」和游戏设置按钮的焦点环变圆（#1067）
- **主图横幅**：底部 1 像素的亮线消失了（#1001）
- **损坏的 NUP 或 RomFS**：构建会以明确的原因停止，并校验 NUP 目录（#1130）
- **测试窗口**：不再播放可能让线程永远卡住的淡入淡出（#1121，@Fbenhaddou）
- **Windows、Qt 前端**：带 Zlib 或 LZ4 内联着色器的 Unreal 游戏、Oodle 和 LZ5 解码器、离线处理 LÖVE 和 GameMaker 着色器、离线处理运行时 GLSLC 着色器、过长的链接命令行、精简 IPA 的 RomFS 标识（@taowen）、LLVM 下载、Python 安装器、一键 Defender 排除，以及 es、ko、pt-BR 的 `%ld%%` 和封面回退（#932、#935、#956、#970、#974、#979、#995、#1039、#1045、#1046、#1064、#1084、#1134）

**已知问题**
- **没有用真实设备测试**：真实的 Steam Link 和蓝牙手柄（#797、#987）、LiveContainer（#1049）、向设备传输大型游戏数据（#899、#1036）以及游戏运行时的 Home 菜单暂停（#952）
- **从安装包读取游戏名称**：没有在启动器自己读取名称之前打包的游戏安装包上检查过（#1125）
- **主机模式界面测试**：`testActionsAndNavigation` 尚未检查
- **1.3.1 版本**：它只到过候选版本，所以它的改动（实验性构建器放在开关后面）随本版本发布（#993）

**系统要求**
- iOS 或 iPadOS 26 或更高版本
- 在 Mac 上构建 NVN 游戏：Xcode 27.2 和 macOS 26.6 或更高版本
