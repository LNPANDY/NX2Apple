**v1.2.4: The experimental builder uses more of the Mac for the pipeline archive, with the bundled nxbuild 0.6.4.**

## English

**Changed**
- **Pipeline archive by the load of the Mac**: with the experimental builder, `nxb 0.6.4` starts Apple's compiler runs for the pipeline archive while CPU and memory use stay below 90 %. Before, 3 runs went while the shader step ran. The runs have a lower priority, so the shader step keeps the cores it needs. On a Mac with 8 GB, one run goes at a time (#834)
- **Shader threads from the cores**: `nxb` takes the number of shader threads from the cores of the Mac. Before, it was 10 on every Mac. An M2 Max still gets 10, an M1 gets 6 (#834)

**Known issues**
- **Experimental builder (`nxb build`)**: how much faster a whole build is with `nxb 0.6.4` has not been measured yet. The iPhone and iPad path has not been run on a device (#749, #834)

**Requires**
- iOS or iPadOS 26 or later
- To build NVN games on a Mac: Xcode 27.2 and macOS 26.6 or later

## 中文

**变更**
- **按 Mac 负载编译管线归档**：使用实验性构建器时，`nxb 0.6.4` 会在 CPU 和内存占用低于 90% 时启动 Apple 编译器来生成管线归档。之前在着色器阶段运行时固定为 3 个。这些编译进程的优先级较低，着色器阶段仍能获得所需的核心。在 8 GB 内存的 Mac 上一次只运行一个（#834）
- **着色器线程数取决于核心数**：`nxb` 根据 Mac 的核心数决定着色器线程数。之前所有 Mac 都是 10。M2 Max 仍为 10，M1 为 6（#834）

**已知问题**
- **实验性构建器（`nxb build`）**：尚未测量 `nxb 0.6.4` 让完整构建快了多少。iPhone 和 iPad 路径尚未在真机上运行过（#749、#834）

**系统要求**
- iOS 或 iPadOS 26 或更高版本
- 在 Mac 上构建 NVN 游戏：Xcode 27.2 和 macOS 26.6 或更高版本
