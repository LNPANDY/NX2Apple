**v1.0.1: Games are found in any folder, and the engine moves on.**

## English

**Highlights**

**The shell finds each game by its image**
- The shared game-data folder no longer needs one folder per game
- Each game is matched by the identity of its `romfs.img`, up to two levels below the chosen folder
- The folders can have any names (#441, #443)

**New**
- **Engine update**: upstream's engine moves on, and the engine alone can now do these things. They are upstream's own results and we have not checked them in the launcher: Donkey Kong Bananza (Switch 2, tested through the first level, Mac only) and Hollow Knight play, Dead Cells has a profile, and a game builds from a folder of its files without `prod.keys`. The launcher does not build Switch 2 games or games from a folder of files yet, see #445 (#444)
- **Right stick on the Mac**: Shift plus an arrow key moves the right stick in the game window (#444)
- **Xcode 27.2 for NVN games**: the new engine locks the Metal compiler of Xcode 27.2, and the launcher says so. On Xcode 27.1, update Xcode before you build a game (#447, #444)

**Fixed**
- **Several games in one folder**: the launcher still recognizes the failure message of the new engine and shows its hint (#444)
- **Adding a game after an engine update**: a new shader chain makes the frameworks in the shared app stale. The launcher now asks before the build, then removes the stale frameworks and continues. Stop leaves every installed game as it was (#449)
- **The shared app's folder**: a build no longer saves the folder at the root of a volume. A saved `/NX2Apple-shell` on the read-only system volume is repaired, and a folder that cannot be written stops the build before it starts, with the folder named (#492)

**Requires**
- iOS or iPadOS 26 or later
- To build NVN games on a Mac: Xcode 27.2 and macOS 26.6 or later

## 中文

**重点**

**壳 App 按镜像本身找到每个游戏**
- 共用的游戏数据文件夹不再要求每个游戏一个文件夹
- 每个游戏按它的 `romfs.img` 的标识匹配，在所选文件夹下两层以内查找
- 文件夹叫什么都可以（#441、#443）

**新增**
- **引擎更新**：上游的引擎更新了，仅引擎本身现在能做到下面这些。它们是上游自己的结果，我们没有在启动器里验证过：Donkey Kong Bananza（Switch 2，只测试到第一关，仅 Mac）和 Hollow Knight 可以运行，Dead Cells 有了配置，游戏可从装有其文件的文件夹构建，不再需要 `prod.keys`。启动器目前还不能构建 Switch 2 游戏，也不能从文件夹构建，见 #445（#444）
- **Mac 上的右摇杆**：在游戏窗口里按 Shift 加方向键可操作右摇杆（#444）
- **NVN 游戏需要 Xcode 27.2**：新引擎锁定了 Xcode 27.2 的 Metal 编译器，启动器会提示这一点。使用 Xcode 27.1 的玩家，构建游戏前请先更新 Xcode（#447、#444）

**修复**
- **一个文件夹里有多个游戏**：启动器仍能识别新引擎的失败提示，并显示对应的说明（#444）
- **引擎更新后再添加游戏**：新的着色器链会让共用应用里的框架失效。启动器现在会在构建前询问，确认后移除旧框架并继续构建。选择停止不会改动任何已安装的游戏（#449）
- **共用应用的目录**：构建不再把目录存到宗卷根目录。保存在只读系统卷上的 `/NX2Apple-shell` 会被修复，无法写入的目录会让构建在开始前停下，并指出该目录（#492）

**系统要求**
- iOS 或 iPadOS 26 或更新版本
- 在 Mac 上构建 NVN 游戏：Xcode 27.2 和 macOS 26.6 或更新版本
