**v1.5.0: Multiple build engines, hot framework loading, and Dark Glass / 多构建引擎、游戏框架热加载与暗色液态玻璃**

## English

**Highlights**

1. **Multi-engine workbench (#1368, #1370, #1372, #1374, #1405, #1455, #1473, #1474)**: Switch engines in one click between `nxnative`, self-updating `nxkit 0.10.3 (Beta)` with Ed25519 signature verification, and turnkey `MacNativeGames` guarded to its 5 maintained titles (`MNG` badges) for first-party Mac play, with `S2Arm` behind `NX2APPLE_ENABLE_S2ARM=1`.
2. **Faster rebuilds and incremental refresh (#1296, #1299, #1322, #1323, #1483)**: Version 1.5.0 builds persist `build-seeds` caches so most updates run fast batch refreshes in minutes without the original game package or intermediate build directories, isolated from unstarted build drafts.
3. **Install new games without reinstalling the shared shell IPA (#1217, #1305, #1437)**: Export signed `DmGame.framework` bundles into `Documents/Frameworks` or hot-push them directly on iOS 27 (`glueVersion: 2`), with no shell IPA reinstall required.
4. **Slim shared shell IPA (#1216, #1229, #1270, #1295, #1439)**: `DMMSLTR1` shader trailers and optional bundled payloads move into external `.img` archives so the shared `NX2Apple.ipa` stays a few tens of megabytes for easier sideload signing, paired with foreground `kqueue` `.nxpart` auto-joining (#1481).
5. **Full Shortcuts support (#1395, #1437)**: Built-in 6-step Add to Home Screen guide and an optional Picture-in-Picture walkthrough card support `nx2apple://launch` home screen icons and controller-connect auto-launch shortcuts.
6. **Major Windows build upgrades (#1249, #1253, #1255, #1315, #1317, #1355, #1414, #1447, #1485, #1492)**: Qt adds a general multi-game `BuildQueue`, expands the Oodle Unicorn emulated heap up to 2 GiB on demand for large shader blocks such as Pokemon Violet, fixes Windows and exFAT zero-inode build seed loops (#1456, #1478, #1492), aligns iOS packager contracts, and improves CET, Defender, and Visual C++ diagnostics.
7. **Background audio mixing (#1300, #1438)**: `DM_AUDIO_MIX` lets music or podcasts keep playing into a game without stopping or lock-free callback crackling, alongside atomic audio teardown and `AudRen` thread draining (#1305, #1314, #1395).
8. **Per-game update version badges (#1296, #1457, #1458, #1486)**: Both Supported Games and hero cards surface the latest NX2Apple version that optimized each game (such as `1.5` across a 102-game catalog with 80 titles updated in `1.5.0`) so players know when to rebuild.
9. **Redesigned launcher UI and artwork pipeline (#1392, #1443, #1457, #1458, #1459, #1467, #1468, #1474, #1484)**: Dark Glass design system backed by design tokens, Liquid Glass reserved for navigation layers, rebuilt two-column console mode, three-tier banner fallback with eShop Switch 2 covers across Mac, iOS, and Qt, and an interactive 16:9 iOS cover cropper.
10. **566-commit engine leap from `ccd834e0` to `ff2d3efea61a` (#1226, #1312, #1361, #1448, #1486)**: Covers over 140 game profiles (208 in the engine tree), unlocks higher frame rates and rendering fixes across major titles, and adds Polish and Thai game language options.

**New**
- **Dark Glass design system and state gallery**: the Mac launcher moves to a single dark palette backed by `design-tokens/tokens.json`, removes light mode branches, keeps Liquid Glass strictly in navigation surfaces, standardizes sheet layouts, and adds `--gallery` (`NX_GALLERY=1`) to inspect every view and failure state locally (#1458, #1459, #1474 by @v0lumehi)
- **Built-first library, single-screen Builds, and redesigned console mode**: playable Mac and iOS builds sort ahead of muted unbuilt titles, Builds returns to a single screen without truncated stage ETAs, opening Builds matches pre-redesign speed, and console mode uses a one-row home screen and two-column detail pages (#1392 by @jonochocki, #1443 by @v0lumehi, #1457, #1474)
- **Multi-engine workbench (`nxnative`, `nxkit`, `MacNativeGames`, `S2Arm`)**: switch engines from a compact top dropdown with short version badges and one-click updates, try `nxkit 0.10.3 (Beta)` on Apple silicon Macs with signed Ed25519 self-updates, run `MacNativeGames` with rootless Python 3.14 and shared fonts guarded to its 5 officially maintained titles (`MNG` badges), keep `S2Arm` hidden behind `NX2APPLE_ENABLE_S2ARM=1` by default, and omit `--update` and `--dlc` flags on unencrypted `.nup` and dump folder inputs (#1368, #1370, #1372, #1374, #1405, #1455, #1473, #1474)
- **Hot-loaded iOS frameworks, iOS 27 hot push, and live `.nxpart` joining**: `ShellHost` and the launchers load signed `DmGame` frameworks from `Documents/Frameworks`, expire stale frameworks on newer shell builds (`glueVersion: 2`), support host-signed hot push on iOS 27 and standalone `.framework` export, and run a foreground `kqueue` directory watcher that auto-joins streaming `.nxpart` parts once quiet (#1217, #1305, #1395, #1437, #1481)
- **6-step Home Screen guide and PiP walkthrough**: `nx2apple://launch` shortcuts gain a 6-step guided setup with an optional zero-extension `AVPictureInPictureController` floating walkthrough card (#1395, #1437)
- **Build seeds, draft isolation, USB link-speed modal, and `.img` recovery**: persistent build seeds power fast incremental refreshes, Mac and Qt sync a 102-game update catalog (80 updated in `1.5.0`) with release badges, refresh batches stay isolated from unstarted build drafts, Mac builds detect `IOUSBHostDevice` link speed (10 Gbps, 5 Gbps, USB 2.0 480 Mbps, or Wi-Fi) with a pre-build transfer mode picker and centered modal transfer sheet, and a three-way recovery flow finds missing `.img` files (#1296, #1299, #1322, #1323, #1439, #1483)
- **`DMMSLTR1` trailers, APFS clones, shared IPA repacking, and loose `.img` claiming**: `DMROMFS1` images hold 16 KiB-aligned `DMMSLTR1` shader trailers, framework-only builds strip `msl` into `.msl-cache` and remind players to replace outdated `.img` copies, framework copies use APFS clones (`cp -c`, #422, #832, #1449 by @Atomsk-debug and @v0lumehi), shared IPAs repack directly with batch transfers, any non-part `.img` name is accepted, and iOS claims matching loose images in `Documents` on launch (#1216, #1229, #1270, #1295, #1439)
- **Artwork pipeline, eShop Switch 2 fallback, and iOS 16:9 cropper**: desktop artwork uses a three-tier banner pipeline (`KnownGameBanners`, `api.nlib.cc`, chunked `titledb`), extracts offline NACP icons, backfills missing iOS covers with synthesized `512x512` square fallback icons (#1457, #1467), resolves official `ec.nintendo.com/apps/<TID>/US|HK` banners for Switch 2 and regional titles across Mac, iOS, and Qt (#1484), and adds an interactive 16:9 pinch-and-pan cover cropper on iPhone and iPad (#1468)
- **Windows batch queue, trash delete, and diagnostics**: Qt adds a general multi-game `BuildQueue` with multi-game folder grouping (#1447), moves deleted games to the Trash while removing them from the shared iPhone app (#1253, #1255 by @Haseenesss), and lists each dependency status in Copy diagnostics (#1249 by @Haseenesss)
- **Audio mix, save portability, and console mode actions**: `DM_AUDIO_MIX` mixes game audio with other iOS apps (#1300), single-game builds append the Team ID to default bundle IDs (#1302), connected controllers show a one-shot quit keycap hint with live in-game settings (#1305, #1395), Mac games carry full saves atomically when libraries move or sit on HFS+ drives (#1118, #1436 by @MartinMajewski and @v0lumehi), Settings adds target display choice (#1283 by @Haseenesss), failed builds alert again in front (#1100 by @Haseenesss), and console mode adds first-click tile selection, wheel row scrolling, and Build or Queue actions (#1289, #1292 by @Haseenesss)

**Changed**
- **Upstream engine and verified game records**: the pin advances from `ccd834e0` through `0c078130` (#1226), `5a4e23a2` (#1312), `94a09447` (#1361), and `0b5fd602` (#1448) to `ff2d3efea61a` (#1486) across 566 upstream commits on shader chain `3dc8a0b295d9`, adding Polish and Thai game language options (#1486) and recording The Legend of Zelda: Ocarina of Time Switch 2 edition played on a Mac up to inside Ganon's Castle (#1308 by @ZhaowTao) and Fire Emblem Fortune's Weave verified at 60 fps on iPhone 18 Pro Max (#1278)
- **Patch queue slimmed from 91 to 56 patches**: `docs/env_switches.tsv` is synthesized automatically, `DmShell` moves under `frontend-ios/Shell`, superseded patches and our custom Joy-Con driver (covered by upstream `pad_jc1`, #1367, #1454, reported by @paulcald90) are dropped, and bridge patches add Nintendo Switch Sports Resort (`04008E001F098000`) resplit shaders (#1480) and zero-inode build seed guards (#1456, #1478, #1492)
- **iOS touch controls simplified**: removed the per-key Hold and Toggle latching mode while keeping standalone `DM_TOUCH_SIZE` and `DM_TOUCH_STICK` settings (#1344)

**Fixed**
- **iOS Cover Flow tail-scroll hang**: replaced `LazyHStack` and synchronous `.scrollPosition` feedback with a fixed-stride `HStack`, render-only `.visualEffect`, discrete `.zIndex`, and deferred selection commits to eliminate the AttributeGraph cycle on cold launch tail scrolling (#1349, #1488)
- **Windows Oodle emulated heap expansion**: `arm64_emu` grows the Unicorn heap in 64 MiB steps up to 2 GiB on demand and scales timeouts for large blocks so large shader chunks no longer fail with `emulated heap full (96 MB)` (#1472, #1485)
- **Engine channel downgrade and experimental build sync**: recorded `.upstream-date`, blocked experimental engine downgrades to older upstream pins, fixed same-version release-candidate upgrades, and refreshed built-in engine version badges (#1475, #1489)
- **Windows/exFAT zero-inode build seed loops and stale `v0` profiles**: fell back to `realpath` loop keys when `st_ino == 0` and rejected or cleaned mismatched `work/profile` folders in `build_seed.py` and `build_ipa_from_nsp.py` (#1456, #1478, #1492)
- **Multi-core CPU BC texture decode and buffer copies**: enabled parallel CPU BC texture decoding on A15 and A16 devices and handled CPU BC buffer-to-texture copies while rejecting unsupported BC readbacks (#446, #777, #1440, #1442 by @v0lumehi)
- **Adaptive iOS RT heaps, arena GPU base latching, and Super Mario Party NVN fixes**: patch `0055` converges `DM_NVN_RT_RECYCLE` heap caps on iOS alongside upstream `RH_SLACK` (#1329, #1486), `nvn_mtl` latches arena GPU base addresses before nested allocations (#1378), and aliased virtual pool flags, sentinel sampler bounds, and `dm_gfx_teardown` state resets keep sessions stable (#1227, #1312, #1486)
- **iOS audio mix crackling, teardown, phone gyro fallback, and shortcut crash**: added lock-free audio prebuffering for 1024-frame mixed callbacks and dropped experimental widescreen patch `0060` (#1438), made audio teardown atomic and drained `AudRen` threads before exit (#1305, #1314, #1395), kept the phone gyroscope active when a controller has no gyro (#971, #1365), moved PhotoKit saving off `@MainActor` (#1437), dropped duplicate vibration hooks in `0027` (#1324), and stabilized game settings transitions (#1325)
- **GL/VK build seeds, Re-sign receipts, and build space cleanup**: preserved shared shell `installedDevice` receipts after IPA exports, inferred and self-healed GL and Vulkan build seeds (#1396, #1438), cleaned failed shader `.part` files on full drives (#1281 by @Haseenesss), avoided double-counting extracted files on rebuilds (#1257 by @Haseenesss), and localized build stage names (#1256 by @Haseenesss)
- **Mac multi-program host, Windows packager alignment, toolchain diagnostics, and l10n**: added `input_preferences_mac.h` for multi-program Mac hosts (#1316 by @gxt43), aligned Qt's `build_app.py` and `IOS_CPU` with `build_ipa.sh` (#1414), ran CET-blocked .NET tools via `dotnet` with POSIX signal guards and dynamic `metal-tt` lookup (#1315 by @1804328), hardened elevated Defender scripts (#1317), skipped stripped Defender prompts and diagnosed missing Visual C++ 2015-2022 (x64) runtimes and NTSTATUS compiler crashes (#1355), and updated German localization checks (#1359)

**Known issues**
- **Tears of the Kingdom and Ocarina of Time shader split hang**: dropping patch `0024` for the shader chain rule means zstd hangs during shader splitting on these two titles can return until `seedds/nxnative#1463` lands upstream (#1448)
- **First rebuild of existing NVN games**: because the shader chain moved to `3dc8a0b295d9`, previously built NVN games rebuild once on their first Play (#449)
- **Hardware coverage on late fixes**: Cover Flow tail scrolling (#1488) was verified on the iPadOS Simulator and not yet on a physical iPadOS 26 device, while the Windows Oodle heap expansion (#1485) and zero-inode seed fixes (#1456, #1478, #1492) were verified with regression suites on macOS and not yet on physical Windows hardware

**Requires**
- iOS or iPadOS 26 or later
- To build NVN games on a Mac: Xcode 27.2 and macOS 26.6 or later

## 中文

**重点**

1. **多构建引擎支持（#1368、#1370、#1372、#1374、#1405、#1455、#1473、#1474）**：新增开箱即用且限定 5 款官方维护游戏（含 `MNG` 徽章）的 `MacNativeGames` 与内置 Ed25519 验签自更新的 `nxkit 0.10.3 (Beta)`，一键切换构建引擎并强化第一方大作 Mac 端体验，默认通过 `NX2APPLE_ENABLE_S2ARM=1` 隐藏实验性 `S2Arm`。
2. **重构大提速与快速刷新（#1296、#1299、#1322、#1323、#1483）**：`1.5.0` 构建持久化 `build-seeds` 种子缓存，大多数更新不再需要原始游戏包或中间构建目录，几分钟即可批量快刷，且刷新批处理与未开跑的草稿完全隔离。
3. **装新游戏免重装壳 IPA（#1217、#1305、#1437）**：可导出已签名 `DmGame.framework` 放入 `Documents/Frameworks` 或在 iOS 27 上直接宿主签名热推送（`glueVersion: 2`），无需反复重装壳 IPA。
4. **共享壳 IPA 大瘦身（#1216、#1229、#1270、#1295、#1439）**：`DMMSLTR1` 着色器尾块与非必须内置文件合入外部 `.img` 镜像，共享壳 `NX2Apple.ipa` 仅数十 MB，大幅便于侧载签名，并配合前台 `kqueue` 监听与稳态 `.nxpart` 自动合片（#1481）。
5. **全面支持快捷指令（#1395、#1437）**：内置 6 步添加到手机主屏幕向导与零扩展画中画（PiP）悬浮跟步教程，支持 `nx2apple://launch` 桌面图标直开游戏及连接手柄自动启动等快捷指令操作。
6. **Windows 构建大幅进化（#1249、#1253、#1255、#1315、#1317、#1355、#1414、#1447、#1485、#1492）**：新增通用多游戏批量构建队列 `BuildQueue`，模拟堆按需扩容至 2 GiB 解决《宝可梦 紫》等大块 Oodle 着色器解压报错，修复 Windows 与 exFAT 零 inode 构建种子误报（#1456、#1478、#1492），对齐 iOS 打包契约并加强 CET、Defender 与 Visual C++ 诊断。
7. **后台音频混音（#1300、#1438）**：`DM_AUDIO_MIX` 支持后台播放音乐或播客进入游戏不停止且无爆音，配套原子音频退出释放与 `AudRen` 线程排空（#1305、#1314、#1395）。
8. **游戏专属更新版本标识（#1296、#1457、#1458、#1486）**：「支持的游戏」列表与主图卡片展示各款游戏最近优化的 NX2Apple 版本号（如 `1.5`，覆盖 102 款目录游戏中的 80 款本轮新增或优化游戏），方便判断是否需要重编。
9. **启动器界面全面进化（#1392、#1443、#1457、#1458、#1459、#1467、#1468、#1474、#1484）**：全系升级为深邃暗色液态玻璃（Dark Glass）设计系统并重制双栏主机模式，配三级桌面横幅回退、三端任天堂商店 Switch 2 横幅兜底与 iOS 16:9 交互式封面裁剪。
10. **跨越 566 次上游提交的引擎大跃迁（`ccd834e0` 至 `ff2d3efea61a`，#1226、#1312、#1361、#1448、#1486）**：支持超 140 款游戏配置（引擎仓实计 208 款），多款大作解锁高帧率与大量渲染修复，并新增波兰语与泰语支持。
