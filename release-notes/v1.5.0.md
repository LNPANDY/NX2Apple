**v1.5.0: Hot framework loading, fast refresh, and engine sync / iOS 热加载游戏框架、快速刷新与引擎同步**

## English

**Highlights**

**Hot framework loading and fast game refresh (#1217, #1296, #1299)**
- Hot-load signed `DmGame` frameworks from `Documents/Frameworks` on iPhone and iPad, including host-signed hot push on iOS 27 (#1217, #1305)
- Persistent build seed caches, a 56-game update catalog, fast-first batch refresh, and missing `.img` recovery across Mac and Windows (#1296, #1299, #1322, #1323)
- `DMMSLTR1` shader trailers inside `.img` archives, stripped framework shaders, shared IPA repacking, and automatic claiming of loose RomFS images in `Documents` (#1216, #1229, #1270, #1295)
- Upstream engine synced through `0c078130` and `5a4e23a2` (shader chain `d254f45e8002`), with the fork patch stack slimmed down to 52 patches (#1214, #1215, #1226, #1312, #1329)

**New**
- **Hot-loaded iOS game frameworks and iOS 27 hot push**: `ShellHost` and the launcher load signed `DmGame` frameworks from `Documents/Frameworks` without rebuilding the shell IPA, expire stale hot frameworks when a newer shell build arrives, and sign hot-pushed frameworks with the host bundle ID on iOS 27 (#1217, #1305)
- **Fast refresh build seeds, update catalog, and batch refresh**: builds persist seed caches for fast incremental refreshes, Mac and Qt sync a 56-game update catalog with release badges in Supported Games and on the hero card, a batch refresh sheet queues fast refreshes first, and a three-way recovery guide locates missing `.img` files on external drives, in Finder or Explorer, or in iPhone `Documents` (#1296, #1299, #1322, #1323)
- **`DMMSLTR1` shader trailers, shared IPA repacking, and loose image claiming**: `DMROMFS1` images carry 16 KiB-aligned `DMMSLTR1` shader trailers for zero-copy loading, framework-only builds strip embedded `msl` into `.msl-cache` and upgrade external-drive images in place, shared IPAs repack directly with batch transfers, any non-part `.img` filename is accepted, and the iOS shell claims matching loose `.img` files in `Documents` on launch (#1216, #1229, #1270, #1295)
- **iOS background audio mixing, Team ID bundle suffix, and controller quit hint**: `DM_AUDIO_MIX` lets game audio mix with other apps (#1300), single-game builds append the developer Team ID to the default bundle ID (#1302), and a connected controller shows a one-shot quit keycap hint below the in-game gear button (#1305)
- **Target display choice, console mode actions, and dependency diagnostics**: Settings lets you pick the display a game opens on (#1283, @Haseenesss), console mode selects a tile on first click, scrolls between rows with the wheel, and offers Build or Add to queue on unbuilt game pages (#1289, #1292, @Haseenesss), failed builds notify again even in front (#1100, @Haseenesss), and Copy diagnostics in Qt names each dependency (#1249, @Haseenesss)

**Changed**
- **Upstream engine and verified games**: the pin advances through `0c078130` (#1226) to `5a4e23a2` across 125 upstream commits on shader chain `d254f45e8002` (#1312), and Fire Emblem Fortune's Weave is recorded as verified on iPhone 18 Pro Max (#1278)
- **Patch queue and `DmShell` layout**: `docs/env_switches.tsv` is synthesized automatically, superseded patches are dropped, fix-on-fix patches are squashed, and `DmShell` lives under `frontend-ios/Shell`, bringing the patch stack from 92 to 52 patches (#1214, #1215, #1312, #1316, #1329)
- **iOS touch controls simplified**: the per-key Hold and Toggle latching mode is removed while keeping standalone `DM_TOUCH_SIZE` and `DM_TOUCH_STICK` settings (#1344)

**Fixed**
- **Adaptive iOS render-target heap convergence**: patch `0055` converges `DM_NVN_RT_RECYCLE` placement heap pool caps under low memory and dispatch pressure on iOS while keeping macOS defaults (#1329)
- **NVN aliased virtual pools and sampler bounds (Super Mario Party)**: aliased virtual memory pools (`vmode == 1`) inherit physical backing storage flags while keeping `CPU_NO_ACCESS` map checks and sparse `vmode == 2`, out-of-range sentinel sampler IDs such as `4095` no longer log false `[RED]` errors, and `dm_gfx_teardown` resets sampler and NVN helper caches across iOS sessions (#1227, #1312, seedds/nxnative#2519, seedds/nxnative#2513)
- **iOS shell teardown, bigstack exit, and settings transitions**: fixed guest `bigstack` exit crashes, drained `AudRen` audio threads before `dm_audio_stop_all` to prevent `SIGTRAP` in `aout_free`, restored shell focus after quitting (#1305), dropped duplicate forced vibration hooks in patch `0027` (#1324), and stabilized segmented and switch transitions in game settings (#1325)
- **Multi-program Mac host builds**: added the missing `input_preferences_mac.h` include when joining the default preferences domain at run time (#1316, @gxt43)
- **Windows toolchain, stripped Defender, and missing runtime diagnostics**: CET-blocked .NET tools run through `dotnet` with POSIX signal guards and dynamic `metal-tt` lookup (#1315, @1804328), Defender elevation runs via a UTF-8 BOM script with preserved caller read ACLs, safe working-directory cleanup, and stripped CLIXML progress (#1317), stripped Windows editions without Defender skip the pre-build prompt cleanly while missing Visual C++ 2015-2022 (x64) runtime DLLs and NTSTATUS compiler crashes are diagnosed directly (#1355), and deleting a game in Qt removes it from the shared iPhone app (#1253, @Haseenesss)

**Requires**
- iOS or iPadOS 26 or later
- To build NVN games on a Mac: Xcode 27.2 and macOS 26.6 or later

## 中文

**重点**

**iOS 热加载游戏框架与快速增量刷新（#1217、#1296、#1299）**
- iPhone 与 iPad 壳应用支持从 `Documents/Frameworks` 热加载已签名 `DmGame` 游戏框架，并支持 iOS 27 宿主签名热推送（#1217、#1305）
- Mac 与 Windows 双端新增持久化构建种子缓存、56 款游戏更新目录、快优先批量刷新队列与缺失 `.img` 恢复引导（#1296、#1299、#1322、#1323）
- 支持在 `.img` 归档尾部封装 `DMMSLTR1` 着色器子镜像、剥离仅框架构建内嵌着色器、直接重打包共享 IPA，并自动认领 `Documents` 下的松散 RomFS 镜像（#1216、#1229、#1270、#1295）
- 上游引擎同步推进至 `0c078130` 与 `5a4e23a2`（着色器链 `d254f45e8002`），分支补丁队列精简收敛至 52 个（#1214、#1215、#1226、#1312、#1329）

**新增**
- **iOS 游戏框架热加载与 iOS 27 热推送**：`ShellHost` 与启动器支持从 `Documents/Frameworks` 动态加载已签名 `DmGame` 框架而无需每次重编整个壳 IPA，新版壳应用到站时自动淘汰过期热加载框架，并在 iOS 27 上使用宿主 Bundle ID 签名热推送框架（#1217、#1305）
- **快速刷新构建种子、游戏更新目录与批量刷新**：构建过程持久化种子缓存以支持快速增量刷新，Mac 与 Qt 双端同步 56 款游戏更新目录并在「支持的游戏」与主图卡片展示版本角标，批量刷新队列按快优先排序，同时为缺失的 `.img` 提供外置盘探针、Finder 或资源管理器定位以及从 iPhone `Documents` 拉取的三向恢复引导（#1296、#1299、#1322、#1323）
- **`DMMSLTR1` 着色器尾块、共享 IPA 重打包与松散镜像认领**：`DMROMFS1` 镜像支持在尾部封装 16 KiB 对齐的 `DMMSLTR1` 着色器子镜像实现零拷贝加载，仅框架构建将内嵌 `msl` 剥离至 `.msl-cache` 并支持就地升级外置盘镜像，共享 IPA 支持直接重打包与多游戏批量传输，允许任意非分片 `.img` 文件名，且 iOS 壳应用启动时自动认领 `Documents` 下匹配的松散 `.img` 文件（#1216、#1229、#1270、#1295）
- **iOS 后台音频混音、默认 Bundle ID 团队后缀与手柄退出提示**：`DM_AUDIO_MIX` 支持游戏音频与其他应用混音播放（#1300），单游戏构建在默认 Bundle ID 末尾追加开发者团队 ID（#1302），连接实体手柄时在游戏内齿轮按钮下方展示一次性的退出键位提示胶囊（#1305）
- **目标显示器选择、主机模式操作与依赖诊断**：设置中可选择游戏打开的目标显示器（#1283，@Haseenesss），主机模式首次点击先选中磁贴、滚轮支持跨行切换并在未构建游戏页面提供「构建」或「加入队列」（#1289、#1292，@Haseenesss），构建失败通知可在前台再次弹窗提醒（#1100，@Haseenesss），Qt 版复制诊断信息会逐项列出依赖状态（#1249，@Haseenesss）

**变更**
- **上游引擎与实机验证记录**：上游固定点经由 `0c078130`（#1226）跨 125 个提交同步至 `5a4e23a2`，对应着色器链 `d254f45e8002`（#1312），并记录《Fire Emblem Fortune's Weave》在 iPhone 18 Pro Max 上的真机验证通过（#1278）
- **补丁队列与 `DmShell` 目录结构**：改为自动合成 `docs/env_switches.tsv`、清理被上游吸收的补丁、合并修复补丁并将 `DmShell` 迁入 `frontend-ios/Shell`，分支补丁队列从 92 个收敛至 52 个（#1214、#1215、#1312、#1316、#1329）
- **精简 iOS 虚拟触控模式**：移除单键按住或切换锁存模式，同时完整保留独立的 `DM_TOUCH_SIZE` 与 `DM_TOUCH_STICK` 设置（#1344）

**修复**
- **iOS 回收渲染目标堆自适应收敛**：新增补丁 `0055`，在低内存与高频提交压力下收敛 iOS 端 `DM_NVN_RT_RECYCLE` 放置堆池容量上限，同时保持 macOS 默认行为（#1329）
- **NVN 别名虚拟内存池与采样器越界保护（Super Mario Party）**：`vmode == 1` 别名虚拟内存池在贴图上传时继承底层物理存储池标志，同时保留 `CPU_NO_ACCESS` 映射拦截与预映射稀疏模式（`vmode == 2`），`4095` 等越界哨兵采样器 ID 不再误报 `[RED]` 错误，同时 `dm_gfx_teardown` 在 iOS 会话切换时重置采样器与 NVN 辅助缓存（#1227、#1312、seedds/nxnative#2519、seedds/nxnative#2513）
- **iOS 壳资源释放、`bigstack` 退出与设置动画**：修复客户机 `bigstack` 退出崩溃、在 `dm_audio_stop_all` 前先排空 `AudRen` 音频线程消除 `aout_free` 的 `SIGTRAP` 并恢复退出后的壳界面焦点（#1305），移除补丁 `0027` 中与上游重复的强制震动钩子（#1324），并稳定游戏设置页分段控件与开关切换动画（#1325）
- **多程序游戏 Mac 宿主构建**：为运行时加入默认偏好域补充缺失的 `input_preferences_mac.h` 头文件引用（#1316，@gxt43）
- **Windows 工具链、精简版 Defender 与缺失运行库诊断**：在受 CET 拦截环境下通过 `dotnet` 启动 .NET 工具并补充 POSIX 信号兼容与动态 `metal-tt` 查找（#1315，@1804328），通过带 UTF-8 BOM 的提权脚本执行 Defender 排除并保留调用方读取 ACL、安全清理工作目录及过滤 CLIXML 进度噪音（#1317），无 Defender 的精简版 Windows 自动跳过构建前提示并直接诊断缺失的 Visual C++ 2015-2022 (x64) 运行库及 NTSTATUS 编译器崩溃码（#1355），同时 Qt 版删除游戏时会一并从共享 iPhone 应用中移除（#1253，@Haseenesss）

**系统要求**
- iOS 或 iPadOS 26 及以上版本
- 在 Mac 上构建 NVN 游戏：Xcode 27.2 与 macOS 26.6 及以上版本
