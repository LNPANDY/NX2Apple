# The game library

- library-01: Rebuilding a game keeps one library entry and its custom art.
- library-02: Removing a game from the library never deletes its app, its saves or its inputs.
- library-03: Play is offered only for a game whose app is there and complete.
- library-04: Given a game in a library folder, its log is read from log/<title ID>.log beside the app.
- library-05: The iPhone shell lists every game bundle and keeps a broken one in the list with its reason.
- library-06: Key art, the hero and Cover Flow draw without clipped or missing art. (manual)
