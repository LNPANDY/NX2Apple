# Settings, launch options and saved choices

- settings-01: Whatever launch options an older launcher left in the library file, moving them into the game's preferences never overwrites a saved choice.
- settings-02: Play passes only overrides and DM_LAUNCHER=0, never a copy of the saved choices of an app that reads them itself.
- settings-03: A saved option that a newer build no longer offers falls back to its default.
- settings-04: The build target saved by an older version is carried over.
- settings-05: On the iPhone, a saved value the game no longer offers reads as the default.
- settings-06: On this Mac, no env.txt line hides a saved choice of the same game.
- settings-07: On this Mac, the repository path and the shell root in the launcher's preferences exist, and the shell root is not the root of a volume.
