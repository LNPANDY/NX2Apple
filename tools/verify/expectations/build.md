# Build a game

- build-01: When a build stops with a message the engine's scripts print, the launcher shows the matching failure row with its fix.
- build-02: The failure patterns match what the engine's scripts print at the current pin.
- build-03: Given a build folder in iCloud Drive or another cloud folder, when the player presses build, then the launcher stops at once and says why.
- build-04: Given a mixed set of dumps dropped on the build page, each file lands in its row by title ID.
- build-05: Given a prod.keys with a wrong header key, the key check says so before the build starts.
- build-06: Free space never removes the finished app, its archive or the input dumps.
- build-07: A release app builds with the tools and the Python inside it, without Homebrew.
- build-08: On Windows, given a folder named the way players name them, the Qt front end finds the base game, the update and the DLC.
- build-09: A verified game built for This Mac with the candidate reaches gameplay. (manual)
