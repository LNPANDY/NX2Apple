# Install on an iPhone or iPad

- install-01: The commands that sign, install and copy a game into the shell are exactly the expected ones.
- install-02: The shell root is never saved at the root of a volume.
- install-03: Given Xcode accounts in the current format, the team menu lists the teams.
- install-04: Given a free Apple ID signature with two days or fewer left, the launcher marks it urgent.
- install-05: On this Mac, devicectl lists the paired devices as JSON the launcher can read.
- install-06: A verified game built for iPhone installs into the shell, plays, and keeps its save after a re-sign. (manual)
