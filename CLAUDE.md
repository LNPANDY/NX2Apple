# Notes for Claude

- Read [AGENTS.md](AGENTS.md) first: this repository's layout and rules. For engine work read [engine/AGENTS.md](engine/AGENTS.md) too, upstream's guide from seedds/nxnative at the pin. `engine/` is made by `python3 tools/engine.py sync` (the SessionStart hook in `.claude/settings.json` runs it).
- For an issue or a pull request, follow [CONTRIBUTING.md](CONTRIBUTING.md), section "For AI agents and other tools", and the templates in `.github/`.
- A PR that changes the launcher needs before and after screenshots: see "For AI agents and other tools" in CONTRIBUTING.md for how to capture them and attach them with `gh pr create --attach`.
- The engine (`dm/`, `scripts/`, `docs/`, `ref/`) is not committed here: it is seedds/nxnative at `.upstream-ref` plus the patch queue in `patches/`, built into `engine/` (git-ignored). Upstream first: a fix goes to seedds/nxnative as a pull request, and becomes a patch only while the fork has to carry it. Work in `engine/`: commit there, then `python3 tools/engine.py export` turns the commits into patches with their header (see [patches/README.md](patches/README.md)). Never add files under `dm/`, `scripts/`, `docs/` or `ref/` at the root: `pr-scope` fails it and `.gitignore` ignores them.
- **Commit with your own git identity, never upstream's.** Use the one configured for your clone, or your own name and email. AGENTS.md ends with `git -c user.name=seedds -c user.email=…` because it is written for seedds/nxnative, where seedds is the maintainer. Do not copy that line here: it makes fork commits, and the `From:` line of patches made with `tools/engine.py export`, show upstream's author (six commits on 2026-10-30 did, including `v0.7.2`, and patch 0033 in #230).
